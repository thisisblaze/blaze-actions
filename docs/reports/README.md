# Automated Sweep Reports

This directory archives reports generated by AI maintenance workflows (e.g., `/09-maintain-docs`, `/12-best-practice-audit`, `/13-deep-cicd-maintenance`).

These automated sweeps verify that all code, workflows, and documentation inside `blaze-actions` remain fully compliant with the **February 2026 Standards** across all supported environments (AWS, GCP, Azure).

Reports are organized by year and month (e.g., `YYYY/MM/YYYY-MM-DD-REPORT-TYPE.md`).
